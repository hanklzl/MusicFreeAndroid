# APK 内置青听音源与设备私有配置

> 文档状态：v1.2.23 发布方案
> 适用范围：内置元力兼容音源、用户在设备输入的网关配置、插件 HTTP 日志

## 分发边界

APK 只内置音源 JavaScript 和其目录，不包含任何默认 appId、签名秘密、设备凭据、ticket 或加密后的共享凭据。用户自行在设备上提供获授权的配置。本次不实现“APK 带有密文及解密能力即可免配置使用”的方案；只分发不含凭据的代码和安装包。

保留元力KW、元力KG、元力WY、元力QQ、元力MG、bilibili 身份和旧歌曲主键。内置版本由 APK 控制，移除公网 srcUrl；旧订阅或同名外部文件不能静默替换内置实现。外部插件不能仅靠冒用平台名读取此私有配置。

音源更新随 APK 升级分发，内置音源不依赖远程订阅。公开发行包沿用现有 GitHub Release 和版本清单更新链路；包内不带授权配置。

## 设备配置

五个音乐平台继续使用用户变量名 `qingGatewayAuth`，值是包含 `appId`、`signSecret`、`appVersion`、`deviceId` 四个字符串字段的私有 JSON。bilibili 不需要网关配置。没有默认真实值，也不在说明中提供真实配置。

入口为插件列表中的“用户变量”；该输入框隐藏字符并使用密码键盘类型。读取损坏配置会显示错误，允许重新输入，或留空保存以清除。保存先验证与持久化，成功后才刷新运行实例。

`GatewayCredentialStore` 使用 AndroidKeyStore 生成的设备 AES 密钥，以 AES-GCM、随机 IV 和平台名 AAD 加密用户输入，写入 `Context.noBackupFilesDir`。普通 DataStore 不再保存该变量；读到旧明文配置时，先写入私有存储再移除旧项。密钥失效、密文篡改和无法写入必须显式失败，不回退明文。

配置只在运行时按需解密。该设计保护静态磁盘与常规备份，不承诺防御已控制设备、运行时调试或恶意改版 APK。重装、跨设备恢复后需重新配置；原有历史备份中的明文不会被追溯删除。

私有变量写入及读取迁移串行化，读取使用最新快照，避免旧 Flow 事件覆盖新配置。

Android 系统备份及设备迁移排除整个 `plugin_meta.preferences_pb`，防止尚未迁移的旧明文被复制；因此其中的插件启停、排序、变量和订阅也不随系统备份恢复。应用手动备份原本不包含此文件。保存先清理普通存储中的旧凭据，再原子更新密文；若密文更新失败，旧密文保留，但普通非敏感变量可能已经保存，界面会报告失败。

## HTTP 日志

`PluginHttpLogSanitizer` 只处理日志，不改变实际请求和返回给 JS 的数据。

- 请求头默认隐藏值，只保留少数非敏感诊断头。
- URL 去除 userinfo、fragment，隐藏全部 query 值。
- `/gateway/ticket` 和 `/music/resolve-url` 请求、响应正文完全省略。
- 其他 JSON 递归隐藏敏感字段；不能可靠解析或过大的正文不记录原文。
- 失败异常不保留原 message、cause 或 suppressed，只留异常类型。

用户要求对凭据和票据脱敏，覆盖旧 AGENTS 文档中第一阶段暂不脱敏的历史口径；普通非敏感诊断依旧保留。
