# APK 内置青听兼容音源

> 文档状态：当前规范（v1.2.24 发布方案）
> 适用范围：BuiltinQingSources、PluginManager 与插件回归测试

APK assets 内置六个不含凭据的 1.2.3 插件：元力KW、元力KG、元力WY、元力QQ、bilibili、元力MG。保留原平台名称和 primaryKey，已有歌单无需转换。APK 升级决定音源码版本；插件不声明外部 srcUrl，单独更新这些插件不会访问订阅服务器。

启动时先校验全部 APK 资源的 SHA-256，再将代码写入应用私有 plugins 目录。变更或缺失的副本会修复。禁用、排序及用户变量仍以原平台名保存，不因代码升级清空。卸载后下次启动会重新安装；需要停止使用时应禁用。

同名旧插件文件保留在磁盘便于恢复，但不再形成第二个活动平台或失败列表项。外部订阅、本地文件与下载插件不能用其他代码覆盖内置平台名或内置文件名。此限制在元数据读取后、用户变量注入前执行。普通插件仍沿用原安装与更新行为。

qingGatewayAuth 只会注入名称和源码哈希均与 APK catalog 一致的运行实例；初始注入与变量刷新均检查。目录可写入文件不代表可信，单纯复用平台名称也不代表可信。资源与 catalog 必须作为一个变更维护，修改代码时同步更新哈希。资源中不允许提交真实凭据，安装包本身不提供授权。

验证入口：BuiltinQingSourcesTest 检查身份、完整性修复、完整 catalog 校验失败的原子前置条件和变量隔离；PluginManagerUserVariablesTest 检查运行变量刷新隔离；PluginManagerHttpLifecycleTest 使用 MockWebServer 检查外部覆盖拒绝和内置更新无请求。既有独立测试显式关闭内置来源以维持原夹具边界。Android 设备验收仍需验证旧歌单播放、禁用状态保留和 APK 升级，不以离线测试代替真实授权或媒体可用性验证。
